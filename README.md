# 🌿 GIS-RS — Forestry & Ecology Analysis Using GIS & Remote Sensing

Detection of human and natural effects on forest cover and ecology
using GIS tools and satellite remote sensing data.

---

## 📌 Overview

This project conducts a geospatial analysis of the **Changsari region, Guwahati, Assam**
over a 4-year period (2018–2022) to detect and quantify the impact of both human
activities and natural processes on local forestry and ecological conditions.
Satellite imagery and GIS tools were used to track land use changes, vegetation
loss, and environmental degradation over time.

---

| Parameter     | Details                          |

| Location      | Changsari, Guwahati, Assam       |
| Study Period  | 2018 – 2022                      |
| Focus         | Forestry, Ecology, Land Use      |

---

## 🚀 Key Analyses

- 🌲 **Forest Cover Change Detection** — Tracking vegetation loss/gain over 4 years
- 🏗️ **Human Impact Assessment** — Identifying urbanization, deforestation, and land encroachment
- 🌊 **Natural Effects Analysis** — Monitoring flood plains, erosion, and seasonal changes
- 🗺️ **Land Use / Land Cover (LULC) Mapping** — Multi-temporal classification of satellite data
- 📉 **Environmental Degradation Tracking** — Quantifying ecological changes using spectral indices (NDVI, etc.)

## 📊 Methodology
```
Satellite Image Acquisition (Landsat / MODIS)
    ↓
Preprocessing & Atmospheric Correction (ERDAS IMAGINE)
    ↓
Land Use / Land Cover Classification (ArcGIS / QGIS)
    ↓
Change Detection Analysis (2018 → 2022)
    ↓
Human & Natural Impact Assessment
    ↓
Thematic Map Generation & Report
```
